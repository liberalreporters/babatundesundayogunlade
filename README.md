# Babatunde Sunday Ogunlade — Official Public Information Website

Responsive static multi-page website prepared for GitHub + Vercel deployment.

## Pages
Home · About · Profile & Experience · Public Priorities · Media Centre · News & Updates · Photo Gallery · Contact · Privacy

## Deployment
The site is static HTML/CSS/JS and requires no build command. Connect the repository to Vercel and deploy the production branch.

## Content standard
This build intentionally avoids invented contact details, credentials, endorsements, election claims, fabricated news or fabricated statistics. Replace placeholders only with verified material.
